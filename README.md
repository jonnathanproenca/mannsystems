# Mann Systems Consulting – site

Site estático (HTML, CSS e JS puros). Sem build, sem dependências.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
   - Para uma URL mais curta, nomeie o repositório `SEU-USUARIO.github.io`.
   - Para domínio próprio (ex.: `www.mannsystems.com.br`), crie um arquivo `CNAME` com o domínio e aponte o DNS para o GitHub.

## Formulário
Como o GitHub Pages é estático, o formulário abre o WhatsApp ou o e-mail com a mensagem pronta.
Para receber por formulário de verdade, troque por um serviço como Formspree ou Web3Forms.
